# 高级语言源程序格式化处理工具

> C 语言子集编译器前端：**手写词法 + 语法 + AST + 风格化重新输出**
> 1831 行 C11 · 6 大模块 · 12 个文件 · 跨平台零警告

一个用 C11 从零实现的 C 语言子集格式化工具，**不依赖 flex / bison 等代码生成器**，
覆盖 `源码 → 词法分析 → 抽象语法树 → 统一风格重新输出` 的完整编译器前端链路。

---

## ✨ 项目亮点

- **1831 行 C11 代码，从零自研**：手写 DFA 词法分析 + 递归下降语法分析 + 双栈算符优先表达式算法
- **跨平台零警告**：Windows MinGW gcc 8.1.0 与 Linux gcc 11.4 下，格式化输出文件均可被 `gcc -Wall -std=c11 -c` 零警告再次接受
- **统一 AST 表示**：tag + union + 孩子兄弟链表统一表示各类语句
- **工程化设计**：错误诊断精确到行号；注释与预处理行原样保留；Makefile + 8 套对照测试

## 🚀 快速开始

### 编译

```bash
make            # 生成可执行文件 formatter（Windows 下为 formatter.exe）
```

### 格式化单个文件

```bash
./formatter test/01_variables.c
```

将 `test/01_variables.c` 格式化为 Allman 风格、4 空格缩进的 C 源码，输出到标准输出。

### 对比期望输出

```bash
./formatter test/01_variables.c > my_output.c
diff my_output.c test/01_variables_fmt.c   # 期望：无任何差异
```

### 一键编译并运行默认测试

```bash
make run       # 编译并对 test/01_variables.c 运行一遍
```

### 清理

```bash
make clean
```

## 🏗️ 系统架构

```
源代码 ──► 词法分析 (DFA) ──► Token 流 ──► 语法分析
                                                │
        (递归下降子程序 + 双栈算符优先表达式算法)
                                                ▼
                                    抽象语法树 (AST)
                                                │
                            (先根遍历 + Allman 风格重写)
                                                ▼
                                        风格化源代码
```

每个阶段职责清晰、单向流动，便于定位和扩展。

## 🎯 三个核心设计要点

### 1. 词法层：单次扫描的多字符识别

DFA 状态机在一次扫描中识别双字符运算符（`<<` / `>>` / `&&` 等）、十六进制常量、含后缀常量（如 `123L` / `0x1Au`）。
**未匹配的字符通过 `ungetc` 回退输入流**——保证识别正确的同时，避免贪婪吞字符。

### 2. 语法层：右结合赋值的双栈处理

表达式解析采用数据结构课的**操作数栈 + 运算符栈**模型（教科书《Dijkstra 双栈算法》的"不求值只建树"变体）。
`=` 的右结合性是这样实现的：在栈顶遇到 `=` 时，优先级临时**降低**一个刻度，使同优先级的 `=` 继续入栈后弹出合并，
从而正确处理 `a = b = c`。

### 3. 输出层：注释与预处理行的原样保留

注释（`/* ... */` 与 `//`）和 `#define` / `#include` 行**不进入 AST 构造**：
- 词法层：整段打包为 `NO_TRANSLATE_TOKEN`
- 语法层：作为"悬挂"节点挂回 AST
- 输出层：先根遍历遇到此 Token 时**原样回写**

这样既保留原始信息，又避免空产生式污染语法树。

## 🧪 测试覆盖

`test/` 目录下 8 套对照测试，每个文件对应一对 `输入.c` / `期望输出_fmt.c`：

| 测试 | 验证点 |
| --- | --- |
| `00_ident.c`     | 标识符与关键字识别 |
| `01_variables.c` | 变量定义与初始化 |
| `02_int.c`       | 整型常量（含十六进制 / 后缀） |
| `03_char.c`      | 字符常量与转义 |
| `04_punct.c`     | 标点与多字符运算符 |
| `05_full.c`      | 综合程序（含 `//` 注释 + `#include`） |
| `06_float.c`     | 浮点常量（含指数与后缀） |
| `07_nested.c`    | 嵌套作用域与函数调用 |

每个测试可手动用 `diff` 与对应 `*_fmt.c` 期望输出对比验证。

## ⚠️ 已知限制 / 后续可改进

- **C 子集范围**：目前支持 `int / float / char`、数组、函数；**暂不支持** `struct / pointer / enum`
- **错误恢复**：当前策略较简单（遇错立即终止），**暂无** panic-mode 同步恢复
- **平台**：已在 Windows MinGW gcc 8.1.0 与 Linux gcc 11.4 验证通过，**MSVC 未测**
