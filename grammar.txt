 语言范围：C 语言子集（对应任务书 3.3 全部要求）
 文档版本：v1.0（阶段1 产物，语法分析子程序的"图纸"）
============================================================

【说明】
1. 本文法定义语言的词法单位与语法结构，是设计报告的
   "语言定义"一节的内容，也是阶段3 每个递归下降子程序的蓝图。
2. 注释与预处理（#define/#include）不属于文法，由词法层
   gettoken() 直接跳过处理（词法层任务）。
3. 表达式部分：为便于理解，下面按优先级分层书写（教科书写法，
   无左递归）。实际实现时按指导书推荐，用"运算符优先关系表 +
   操作数栈/运算符栈"完成（数据结构课的表达式求值算法，不求值只建树），
   两种写法等价，都避免直接左递归。
4. 终结符用大写表示（与 token.h 中枚举一致）：
   IDENT 标识符  INT_CONST 整型常量  LONG_CONST 长整型常量
   FLOAT_CONST 浮点常量  CHAR_CONST 字符常量
5. ε 表示空串（该语法成分可空缺）。

------------------------------------------------------------
一、程序结构
------------------------------------------------------------
<程序>              ::= <外部定义序列>

<外部定义序列>      ::= <外部定义> <外部定义序列> | <外部定义>

<外部定义>          ::= <外部变量定义>
                      | <函数定义>
                      | <函数声明>

------------------------------------------------------------
二、类型与变量（含数组）
------------------------------------------------------------
<类型说明符>        ::= int | float | char

<外部变量定义>      ::= <类型说明符> <变量序列> ;
<局部变量定义>      ::= <类型说明符> <变量序列> ;

<变量序列>          ::= <变量> , <变量序列> | <变量>
<变量>              ::= IDENT
                      | IDENT [ INT_CONST ]       /* 数组，如 int a[10] */

------------------------------------------------------------
三、函数（定义 / 声明 / 调用）
------------------------------------------------------------
<函数定义>          ::= <类型说明符> IDENT ( <形式参数序列> ) <复合语句>
<函数声明>          ::= <类型说明符> IDENT ( <形式参数序列> ) ;

<形式参数序列>      ::= <形式参数> , <形式参数序列> | <形式参数> | ε
<形式参数>          ::= <类型说明符> IDENT

<实参序列>          ::= <表达式> , <实参序列> | <表达式> | ε
<函数调用>          ::= IDENT ( <实参序列> )      /* 作为表达式因子使用 */

------------------------------------------------------------
四、语句
------------------------------------------------------------
<复合语句>          ::= { <局部变量定义序列> <语句序列> }

<局部变量定义序列>  ::= <局部变量定义> <局部变量定义序列> | ε
<语句序列>          ::= <语句> <语句序列> | ε

<语句>              ::= <表达式语句>
                      | <复合语句>
                      | if ( <表达式> ) <语句>                 /* if 形式1 */
                      | if ( <表达式> ) <语句> else <语句>     /* if 形式2 */
                      | while ( <表达式> ) <语句>
                      | for ( <表达式> ; <表达式> ; <表达式> ) <语句>
                      | return <表达式> ;
                      | break ;
                      | continue ;

<表达式语句>        ::= <表达式> ;

------------------------------------------------------------
五、表达式（按优先级从低到高分 7 层）
------------------------------------------------------------
<表达式>            ::= <赋值表达式>

<赋值表达式>        ::= IDENT = <赋值表达式>      /* 右结合 */
                      | <逻辑或表达式>

<逻辑或表达式>      ::= <逻辑与表达式> || <逻辑或表达式> | <逻辑与表达式>
<逻辑与表达式>      ::= <相等表达式> && <逻辑与表达式> | <相等表达式>

<相等表达式>        ::= <关系表达式> == <相等表达式>
                      | <关系表达式> != <相等表达式>
                      | <关系表达式>
<关系表达式>        ::= <算术表达式> > <关系表达式>
                      | <算术表达式> < <关系表达式>
                      | <算术表达式> >= <关系表达式>
                      | <算术表达式> <= <关系表达式>
                      | <算术表达式>

<算术表达式>        ::= <项> + <算术表达式>
                      | <项> - <算术表达式>
                      | <项>
<项>                ::= <因子> * <项>
                      | <因子> / <项>
                      | <因子> % <项>
                      | <因子>

<因子>              ::= IDENT
                      | INT_CONST
                      | LONG_CONST
                      | FLOAT_CONST
                      | CHAR_CONST
                      | ( <表达式> )
                      | <函数调用>                /* 如 fun(a,b) */
                      | IDENT [ <表达式> ]        /* 数组下标访问 a[i] */

------------------------------------------------------------
六、优先级汇总（与 token.h 枚举一一对应）
------------------------------------------------------------
最高:  ( ) [ ]  函数调用/下标      （定界符/后缀）
      ! ~ 无                       （本语言不含单目运算符）
      * / %                        （乘除取余）
      + -                          （加减）
      < <= > >=                    （关系）
      == !=                        （相等）
      &&                           （逻辑与）
      ||                           （逻辑或）
      =                            （赋值，右结合，最低）
最低:  ; 语句结束

------------------------------------------------------------
七、与 token.h 的对照清单（词法层要识别的全部单词）
------------------------------------------------------------
关键字:   int float char
          if else while for return break continue
常量:     IDENT 标识符
          INT_CONST:   123  0123  0x123   （int 三种形式，编码相同）
          LONG_CONST:  123L               （long，编码不同）
          FLOAT_CONST: 1.5  .5  1.  1.5F
          CHAR_CONST:  'a'  '\n'  '\0'
运算符:   + - * / %   （算术）
          =           （赋值）
          == != > >= < <= （关系）
          && ||       （逻辑）
定界符:   ( ) [ ] { } ; ,
其他:     PREPROCESS：# 开头行（#define #include，整行跳过）
          注释：块注释 /* */ 与行注释 //   （跳过，换行照常计行号）
